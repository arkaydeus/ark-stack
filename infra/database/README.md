Application PostgreSQL is a separate cluster from the platform control database. Public traffic terminates on PgBouncer with `client_tls_sslmode=require`, explicit database/role admission, and no wildcard mapping. Privileged, backup, and bootstrap identities are denied on the public listener.

The `pgbouncer-public` Compose service runs `/usr/bin/pgbouncer` directly on the generated `/var/lib/ark/pgbouncer/pgbouncer.ini`; the image's own entrypoint, which builds a config from environment variables, is bypassed. It runs as uid 1000, the owner of Ark's mode-0600 config, userlist and TLS key, because every capability is dropped. `tests/security/pgbouncer-public.test.ts` enforces that shape and a PgBouncer version of at least 1.25.2 (CVE-2026-6664). `mise run test:pgbouncer` starts the service against a disposable `app-postgres` and connects over TLS with SCRAM as a runtime role.
